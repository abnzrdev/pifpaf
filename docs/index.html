PRODUCT

Built for a focused workflow.

Features and boundaries are described from the repository's current documentation.

01

One creator dashboard

Save links to public Instagram Reels and organize the latest available public performance metrics.

02

Import by URL

Add a canonical public Reel link to associate its metrics with your account.

03

Refresh when needed

Manually refresh a Reel, with a limited background refresh for older entries when visiting the dashboard.

04

Two interface languages

Russian-first product copy with a persistent Russian / English language switch.

05

Scoped accounts

Credentials authentication and PostgreSQL data stored separately by user.

06

Honest API integration

Server-side Apify integration supports live fetching or explicit deterministic mock mode. Missing public metrics are shown as unavailable.
